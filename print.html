Projects

lady-lens

github.com/kimVanRenterghemNew/lady-lens

A deterministic code-graph indexer and MCP server, open source, in pure JavaScript on LadybugDB.

It grew out of building Kura, our own coding agent, and became a package of its own.

It turns codebases (JavaScript/TypeScript, Python, C#) into a queryable knowledge graph of symbols, dependencies (imports, calls, tests), impact analysis and deterministic subgraph extraction for AI coding agents, without heavy LLM overhead.

AST and semantic extraction are combined with a locally trained, reproducible linear ranking model (IDF with a pairwise logistic loss) to sharply cut context bloat and token use for AI agents.

3.4 s for a full sync of a 349-file repository. · 0.2 s for an incremental sync after a change.

Vaultgate

github.com/kimVanRenterghemNew/Vaultgate

Your AI agents use your keys. They never see them.

A local gate between AI agents and the internet. The agent sends a placeholder ({{secret:github_token}}); Vaultgate fills in the real key as the request leaves the computer, and only for the tool, the host and the place in the request that you allowed. Replies are scrubbed before the agent sees them, base64 and hex copies included.

One decision table where the first rule wins and names itself in every response. The vault key is random and wrapped per passkey through the WebAuthn PRF extension; every field is encrypted with XChaCha20-Poly1305. Anything that lasts asks for a touch of your passkey: a program can click a button, it cannot touch a security key.

Preview, version 0.0.1-beta.0. The screenshots show the real portal with test data.
